# Зачем SecondBrain отдельная модель по API — и можно ли без неё

Коротко: отдельная модель по API нужна, **чтобы не тратить лимиты вашей основной модели по подписке** на фоновую
работу — разбор тысяч записей. Стоит это около **100–200 ₽ в месяц, и это максимум**. При этом **SecondBrain работает
и без модели.** Он соберёт ваши чаты, почту и заметки, найдёт что угодно за долю
секунды и даст ChatGPT и Claude читать вашу базу. Модель по API нужна для одного — чтобы к каждой записи появилась
**карточка**: короткая выжимка и проверенные факты. Ниже — простыми словами, что это даёт, почему нужен именно API и
как обойтись без него.

## Что делает программа сама, бесплатно

| | Без модели |
|---|---|
| Собирает чаты ChatGPT и Claude, сессии Codex и Claude Code, почту, заметки | ✅ |
| Хранит всё на вашем компьютере, ничего не отправляет наружу | ✅ |
| Ищет по всему архиву, понимает русские словоформы («договор» найдёт «договора») | ✅ |
| Даёт ChatGPT, Claude, Claude Code, Codex искать и читать вашу базу | ✅ |
| Показывает записи, проекты из ChatGPT и папок, граф ссылок между заметками | ✅ |

## Что добавляет модель

Представьте архив из тысячи длинных чатов. Когда вы спрашиваете ChatGPT «что я решил по клиенту X?», он ищет в базе
и получает **оригиналы** — иногда по сотне страниц. Ему приходится читать всё подряд: это медленно, съедает его
память в чате, и он может перепутать, кто что сказал.

Модель заранее, один раз на запись, делает **карточку**:

- **Выжимка** в 2–3 предложения — нейросеть сразу видит суть, не открывая весь чат.
- **Факты с точными цитатами.** Каждый пункт привязан к дословной фразе из оригинала, а программа сама проверяет,
  что такая фраза там есть. Выдуманный пункт отбрасывается.
- **Кто что сказал.** «Вы решили» и «ассистент предложил» хранятся отдельно — нейросеть не выдаст старый совет за
  ваше решение.
- **Ключевые слова и вопросы** — по ним поиск находит запись, даже если вы формулируете иначе.
- **Автопроекты.** Записи без своего проекта (чаты вне проектов ChatGPT, письма, заметки) модель раскладывает по
  вашим проектам: «Продажи», «Здоровье», название клиента или продукта. Записи «без проекта» обычно сокращаются в
  разы.
- **Связи по смыслу** на графе и частые темы в обзоре базы.

Итог: ChatGPT и Claude отвечают про вашу жизнь и работу быстрее, точнее и с датами — вместо «я не нашёл» или
пересказа не того чата.

## Главное: зачем отдельная модель, если есть подписка

**Чтобы фоновая работа не съедала лимиты вашей основной модели.** У подписки ChatGPT Plus или Claude Pro есть
лимиты: сколько сообщений можно отправить за несколько часов или за неделю. Разобрать архив — это сотни и тысячи
длинных текстов. Если бы этим занималась ваша основная модель по подписке, лимиты кончились бы за час, и в самый
нужный момент вы бы упёрлись в «лимит исчерпан, попробуйте позже» в обычной работе.

Поэтому вся фоновая работа — выжимки, проверка цитат, автопроекты — идёт через **отдельную дешёвую модель по API**.
Ваша подписка остаётся целиком для вас: для разговоров, кода и задач. А когда ChatGPT или Claude ищут в базе, они
читают уже готовые короткие выжимки, а не сотни страниц — это тоже бережёт лимиты подписки.

Вторая причина техническая: подпиской может пользоваться только человек в окне чата, у неё нет «входа для программ».
Программе, которая работает сама в фоне, нужен **API** — отдельный ключ, где платят за объём текста, а не помесячно.

## Сколько стоит

**Содержание — около 100–200 ₽ в месяц, и это потолок.** Обычно выходит меньше: карточка делается один раз на запись,
дальше модель читает только новые и изменённые записи (в обычный месяц — около $0,3, это примерно 25 ₽).

**Больше — только один раз, в самом начале**, если нужно разобрать очень большую кипу накопленных данных. Пример:
архив из ~1 500 записей (около 4 000 карточек) обошёлся один раз примерно в **$4,5 (≈ 370 ₽)**. Если архив в несколько
раз больше — и первая обработка дороже, но тоже один раз. Разложить всю базу по автопроектам — около $0,015.

Защита от неожиданных трат — **месячный потолок** (по умолчанию 450 ₽) в «Настройках»: дойдя до него, обработка
встаёт на паузу до следующего месяца, а записи ждут в очереди. Пока вы не укажете цены модели, платная обработка не
запускается вообще.

## Какой API выбрать

- **Рекомендуем: [Tooken Club](https://tooken.club) и модель GPT-6 Luna.** Очень дёшево, оплата в рублях. Настройка
  — [шаг 8 в START_HERE.md](../START_HERE.md#шаг-8-карточки-отдельный-api-ключ-модели).
- **Любой OpenAI-совместимый API**: OpenAI, OpenRouter, прокси. Работает так же, цены — у провайдера.

## Что уходит модели

Только текст **той записи**, которую она сейчас разбирает (для автопроектов — её короткая выжимка или заголовок и
начало текста, плюс список названий ваших проектов). Пароли и ключи, попавшие в переписку, скрываются до отправки.
Поиск, сбор, граф и подключение нейросетей модель не вызывают. Обработку можно в любой момент выключить в
«Обработке».

## Как обойтись без API

**1. Просто не добавляйте ключ.** Всё из первой таблицы работает. ChatGPT и Claude будут искать в базе и сами читать
оригиналы. Не будет выжимок, проверенных фактов, автопроектов и связей по смыслу. Для небольшого архива (десятки
чатов) этого часто хватает.

**2. Бесплатная локальная модель (Ollama).** Модель работает прямо на вашем компьютере: бесплатно, без интернета,
текст никуда не уходит. Установите [Ollama](https://ollama.com), скачайте модель, в «Настройках» укажите адрес
`http://localhost:11434/v1` и формат запросов «Chat Completions». Минусы честно: нужен мощный компьютер (от 16 ГБ
памяти, лучше с видеокартой), обработка медленнее, а маленькие модели чаще ошибаются в цитатах — такие пункты
программа отбросит, и карточки выйдут беднее.

**3. Сначала без ключа, потом решить.** Можно начать без модели, пожить с поиском, а ключ добавить позже —
новые записи всё это время копятся в очереди и будут разобраны, ничего не потеряется.

## Если сомневаетесь

Начните без ключа. Если ChatGPT или Claude отвечают «не нашёл», путаются в длинных чатах или вы упираетесь в лимиты
подписки — подключите отдельную модель: 100–200 ₽ в месяц максимум, а ваша подписка остаётся для работы.
