# Telegram → SecondBrain

Пишете или пересылаете сообщения своему боту (или в группу, где есть бот), и через несколько секунд они
попадают в базу. Там они ищутся через `brain_search` вместе с чатами, почтой и заметками.

Как это устроено:
- **Ваш собственный бот.** SecondBrain сам забирает новые сообщения у Telegram (long polling), поэтому
  публичный адрес, домен и Tailscale не нужны. Работает на компьютере и на VPS.
- **Сохраняются только подтверждённые чаты.** Бот присылает в чат 6-значный код, вы вводите его в панели.
  Пока чат не подтверждён, сообщения из него **не сохраняются**: если кто-то найдёт вашего бота, в базу
  он ничего не запишет.
- **Одна запись = один чат за один день**, например «Telegram · Входящие · 21 нояб.». Новые сообщения
  дописываются в запись этого дня, правки сообщений обновляют её.
- **Пересланное** хранится с пометкой «Переслано от: Имя» и исходной датой.
- **Файлы** (документы, фото, голосовые, видео) до 20 МБ сохраняются как вложения, текст PDF/DOCX/XLSX
  ищется. Файлы больше 20 МБ Telegram ботам не отдаёт: в записи будет пометка с именем файла.
- **Токен бота** хранится в `store/secrets/telegram-bot.json`, не в базе. На страницу и в ответы он не попадает.

## Подключение (5 минут)

### 1. Создать бота
1. В Telegram откройте **@BotFather** (с синей галочкой) → **Start**.
2. Отправьте `/newbot`.
3. Имя бота: любое, например `Мой SecondBrain`.
4. Адрес бота: латиницей, должен заканчиваться на `bot`, например `my_secondbrain_bot`. Если занят,
   придумайте другой.
5. BotFather пришлёт **токен** вида `1234567890:AAH…` (около 46 символов). Это пароль от бота:
   никому не пересылайте и не вставляйте в чаты с нейросетями.

> **Используйте отдельного бота только для SecondBrain.** Если этот же бот уже работает в другой программе
> (n8n, Make, свой скрипт), они будут мешать друг другу: у бота может быть только один читатель.

### 2. Вставить токен в SecondBrain
1. Панель `http://127.0.0.1:8877` → **«Источники»** → карточка **Telegram** → **«Бот и чаты»**.
2. Вставьте токен → **«Сохранить и проверить»**.
3. Должно появиться «Бот @имя подключён». Источник включится сам.

### 3. Подключить чат
**Личная переписка с ботом** (самый простой вариант):
1. Откройте своего бота в Telegram → **Start** (или отправьте `/start`).
2. Бот ответит кодом из 6 цифр.
3. В панели, в карточке Telegram, появится «Ждут подтверждения». Введите код → **«Подтвердить»**.
   Список обновляется сам раз в 5 секунд.
4. Бот напишет «✅ Чат подключён». Готово: всё, что вы пишете или пересылаете боту, сохраняется.

**Группа** (например «Входящие», куда пишете вы и коллеги):
1. Создайте группу и добавьте в неё бота.
2. Чтобы бот видел **все** сообщения, а не только команды, сделайте одно из двух:
   - **сделайте бота администратором группы** (права можно снять все, кроме нужных по умолчанию); или
   - у @BotFather: `/setprivacy` → выберите бота → **Disable**, затем **удалите бота из группы и добавьте снова**
     (без повторного добавления настройка не применится).
3. Напишите в группу любое сообщение, бот пришлёт код. Подтвердите его в панели.

**Канал**: добавьте бота администратором канала, опубликуйте пост, подтвердите код.

### 4. Проверить
- В подключённом чате отправьте `/status`: бот ответит, сколько сообщений сохранено сегодня.
- В Claude, ChatGPT или Codex: «Найди в SecondBrain то, что я сегодня пересылал в Telegram».

## Старая история чата

Бот видит только **новые** сообщения, начиная с момента подключения. Историю загрузите выгрузкой:

1. **Telegram Desktop** (программа на компьютере, не веб и не телефон) → откройте чат → **⋮** →
   **«Экспорт истории чата»**.
2. Формат **JSON** (не HTML). Медиафайлы можно не выгружать: они не импортируются, в записи будет имя файла.
3. Включите источник Telegram в панели (достаточно сохранить токен), затем:
   ```powershell
   npm run import -- "C:\путь\к\папке\выгрузки"
   ```
   Для всех чатов сразу: Telegram Desktop → Настройки → Продвинутые настройки → **«Экспорт данных из Telegram»**
   → JSON → тот же `npm run import`.

Выгрузка и сообщения бота за один день одного чата **объединяются в одну запись**. Повторный импорт ничего не
дублирует.

## Если что-то не работает

| Что видите | Причина и что делать |
|---|---|
| «Это не похоже на токен бота» | Скопирован не весь токен или лишний текст. Нужно `цифры:буквы` целиком из сообщения BotFather. |
| «Токен не принят Telegram» | Токен с ошибкой, перевыпущен (`/revoke` у BotFather) или бот удалён. Возьмите актуальный: @BotFather → `/mybots` → бот → **API Token**. |
| «У бота включён вебхук» | Бот уже подключён к другой программе. Лучше создать отдельного бота. Если бот точно больше нигде не нужен, нажмите **«Отключить вебхук»**. |
| «Этого бота уже читает другая программа или второй запущенный SecondBrain» | У одного бота может быть только один читатель. Закройте другую программу или второй SecondBrain (например, на ноутбуке и на VPS одновременно) либо заведите второго бота. |
| «Нет связи с api.telegram.org» | Нет интернета, или Telegram заблокирован в сети. Включите VPN/прокси на компьютере с SecondBrain (не только на телефоне). После восстановления связи бот догонит пропущенное. |
| «Telegram просит подождать N с» | Ограничение частоты. SecondBrain сам подождёт и продолжит, ничего делать не нужно. |
| Бот не прислал код | Источник Telegram выключен, или SecondBrain не запущен (`Invoke-RestMethod http://127.0.0.1:8877/api/stats`). Проверьте строку «Последняя проверка Telegram» в карточке. Напишите боту ещё раз. |
| «Код не совпадает» / «Запрос устарел» | Код живёт 30 минут. Напишите в чат ещё одно сообщение, придёт новый код. |
| В группе сохраняются только команды | Включён режим приватности: сделайте бота администратором или `/setprivacy` → **Disable** и **заново добавьте бота** в группу. Карточка Telegram показывает это предупреждение. |
| Сообщения, отправленные до подтверждения, не попали в базу | Так задумано: до подтверждения ничего не сохраняется. Перешлите их боту ещё раз или загрузите выгрузкой. |
| Компьютер был выключен больше суток, часть сообщений пропала | Telegram хранит недоставленные сообщения для бота около 24 часов. Загрузите пропущенный период выгрузкой из Telegram Desktop. |
| Файл не сохранился: «больше 20 МБ» | Ограничение Telegram для ботов. Сохраните файл вручную и положите в папку заметок. |
| Удалённое в Telegram сообщение осталось в базе | Telegram не сообщает ботам об удалениях. Сохранённое остаётся в базе. |
| «Бота удалили из: …» | Бота исключили из группы. Сохранённое осталось. Чтобы продолжить, добавьте бота снова и подтвердите новый код. |
| Группа стала супергруппой | SecondBrain сам переносит подтверждение на новый номер чата. Ничего делать не нужно. |
| `npm run import`: «включите источник Telegram» | Сначала сохраните токен бота в карточке Telegram: это включает источник. |
| `npm run import`: «Файл не читается как JSON» | В Telegram Desktop при экспорте выбран HTML. Повторите экспорт в формате **JSON**. |
| Нужно перестать сохранять чат | Карточка Telegram → «Подключённые чаты» → **«Отключить»**. Сохранённое останется. Выключатель карточки останавливает весь источник. |

## Безопасность

- Токен даёт полный контроль над ботом. Если он утёк, у @BotFather: `/revoke` → новый токен вставьте в панель.
- Бот видит только то, что ему пишут или что пишут в чатах, куда его добавили. Читать вашу личную
  переписку он не может.
- Сообщения боту проходят через серверы Telegram, как и любые сообщения в Telegram.
- В группах с другими людьми их сообщения тоже попадают в вашу базу. Предупредите участников.
