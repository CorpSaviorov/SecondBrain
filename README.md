# SecondBrain — вторая память для ваших нейросетей

Локальное приложение, которое само собирает в одну базу на вашем компьютере:

- чаты **ChatGPT** и **Claude** прямо из аккаунта, каждые 15 минут (вход один раз в отдельном окне);
- сессии **Codex** и **Claude Code**;
- заметки **Obsidian** или любую папку с `.md`;
- **почту** Gmail и Яндекс (только чтение, по паролю приложения);
- вложения: PDF, DOCX, XLSX, PPTX, txt, html, json. Их текст тоже ищется.

И отдаёт эту память нейросетям:
- **Claude Code, Codex, Cursor** на этом компьютере подключаются одной командой;
- **ChatGPT и Claude** в браузере и на телефоне подключаются как коннектор через защищённый шлюз:
  вход по OAuth, каждое подключение подтверждаете вы, доступ только на чтение.

Нейросеть сама ищет в базе, прежде чем отвечать, и знает ваш контекст: проекты, решения,
договорённости, прошлые обсуждения. Пересказывать всё заново больше не нужно.

## Чем отличается от «просто RAG»

| | |
|---|---|
| **Поиск без нейросети** | BM25 и русская морфология (Snowball). Ответ за доли секунды, бесплатно, работает офлайн. |
| **Карточки с цитатами** | Недорогая модель пишет к каждой записи выжимку. Каждый факт в ней привязан к **дословной цитате** из оригинала с датой. Программа проверяет цитату, а пункт без подтверждения отбрасывает. |
| **Различает, кто что сказал** | Ваше решение, совет ассистента и отчёт ассистента «я сделал» хранятся раздельно. |
| **Оригиналы не меняются** | Каждая версия источника сохраняется. Карточка относится к конкретной версии. |
| **Всё у вас** | Одна база SQLite на вашем диске. Сервер слушает только `127.0.0.1`. Ключи и пароли из переписки маскируются в любой выдаче. |
| **Модель любая** | Подойдёт любой OpenAI-совместимый API: OpenAI, OpenRouter, прокси или локальная Ollama. Месячный потолок расходов задаётся в настройках. |

## Установка: отдайте её нейросети

Обычный чат в браузере программу не установит. Нужен **агент с доступом к компьютеру**: Claude Code,
вкладка Code в приложении Claude, Codex или Cursor.

1. Скачайте репозиторий (`Code → Download ZIP` или `git clone`) и распакуйте в папку с **коротким путём**,
   например `Документы\SecondBrain`.
2. Откройте эту папку в агенте.
3. Напишите ему:

```text
Прочитай START_HERE.md и установи SecondBrain по шагам. После каждого шага показывай результат проверки.
```

Агент проверит Node.js и Python, прогонит тесты и проверку на демо-данных. Затем он настроит
автозапуск, подключит Claude Code и Codex и поможет войти в ChatGPT, Claude и почту. Если хотите,
он подключит базу и к ChatGPT и claude.ai.

Требования: **Windows 10/11**, **Node.js 24+**, **Python 3.10+**. Для ChatGPT и claude.ai нужен ещё
бесплатный **Tailscale**. На macOS и Linux ядро тоже работает, см. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Вручную, если хочется самому

```powershell
npm run setup        # пакеты для почты и окно входа в ChatGPT/Claude
npm test             # 117 тестов, все должны пройти
npm run check        # запуск на демо-данных во временной базе: должно быть «всё работает»
npm start            # сервер: http://127.0.0.1:8877
```

Подключение к Claude Code и Codex:

```powershell
claude mcp add --transport http --scope user secondbrain http://127.0.0.1:8877/mcp
codex mcp add secondbrain --url http://127.0.0.1:8877/mcp
```

ChatGPT и claude.ai через шлюз — шаг 7 в [START_HERE.md](START_HERE.md):

```powershell
npm run setup:gateway; npm run check:gateway; npm run gateway:setup
npm run gateway        # затем: tailscale funnel --bg 8787, коннектор в чате, npm run gateway:approve
```

## Что внутри

```
README.md         вы здесь
START_HERE.md     пошаговая установка для нейросети, с проверкой каждого шага
AI_GUIDE.md       как нейросеть должна пользоваться базой (промпт и правила)
app/              приложение: сервер, веб-панель, сборщики, обработка карточек
gateway/          шлюз для ChatGPT и claude.ai (OAuth, подтверждение владельца, только чтение)
docs/             архитектура; REMOTE.md — доступ с других устройств и перенос на VPS
deploy/           службы systemd и конфиг Caddy для сервера на Linux
demo/             выдуманные чаты и заметка для проверки
store/            появится после первого запуска: ваша база (в git не попадает)
```

## Честно об ограничениях

- Автозапуск и окно входа рассчитаны на Windows.
- ChatGPT и claude.ai видят базу, только пока компьютер с ней включён. Чтобы база работала
  круглосуточно, её можно перенести на VPS: [docs/REMOTE.md](docs/REMOTE.md).
- Сбор чатов из аккаунта читает их так же, как сайт в браузере. Если сервис поменяет свой внутренний
  формат, сбор может временно сломаться. Тогда остаётся официальная выгрузка (`npm run import`).
- Свои коннекторы в ChatGPT доступны не на всех тарифах.
- Карточки пишет платная модель, если вы её подключите. Поиск и сбор бесплатны и без неё.
